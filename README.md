# Quran & Decor art catalog

Static catalog of paintings for the Quran & Decor Android TV app, served through jsDelivr:

    https://cdn.jsdelivr.net/gh/ElSifi/quranframe-catalog@main/v1/catalog.json

Generated by `tools/catalog/build_catalog.py` in the app repository. Do not edit by hand.
All artwork is original (AI-assisted) and generated for Quran & Decor.
